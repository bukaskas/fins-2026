## How this list was built

- **Hours** = summed duration (`endsAt − startsAt`) of every lesson session the student is booked on.
- Only sessions that have **already finished** (`endsAt` ≤ now) are counted — future bookings are excluded.
- `CANCELED` bookings are excluded. `RESERVED` / `CONFIRMED` / `COMPLETED` / `NO_SHOW` all count as delivered, because the `attended` flag is set on only 7 of 157 bookings and is not a reliable signal.
- Group lessons count the full session length for each participant.
